# Python Data Structures Assignment

Basic Python exercises covering lists, dictionaries, sets, and tuples.

## Topics Covered

### List
- Create and print a list of five random numbers.
- Insert three new values and print the updated list.
- Print each element using a for loop.

### Dictionary
- Create a dictionary containing a name, age, and address.
- Add a phone number as a new key-value pair.

### Set
- Create a set containing the values 1–5.
- Add the value 6.
- Remove the value 3.

### Tuple
- Create a tuple containing the values 1–4.
- Print the length of the tuple.
